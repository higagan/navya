# Notice on source texts

This project builds tooling to digitize and study printed Sanskrit
philosophy texts. The code in this repository (pipeline, app, scripts) is
MIT-licensed — see [LICENSE](LICENSE).

The underlying books being digitized (e.g. *Avayavaprakaraṇam*,
*Sāmānyanirukti of Gaṅgeśopādhyāya*) are not part of this repository. Their
scans, OCR output, and any substantial transcriptions are intentionally
excluded from version control (see `.gitignore`) because:

- Some editions may still be under copyright depending on publication date
  and jurisdiction, independent of the root text's antiquity.
- Redistribution of full scans/transcriptions is a separate decision from
  open-sourcing the tooling, and hasn't been made yet.

If you fork this project to digitize your own texts, make sure you have the
right to do so before committing scans or full transcriptions to a public
repository.
